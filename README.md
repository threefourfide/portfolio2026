# Portfolio 2026
React + Vite starter based on the supplied Figma screenshots.

## Run locally
npm install
npm run dev

## Edit
Each section has its own component in src/components. Shared styling is in src/styles.css.
Portrait, certificates and background texture are cropped from the supplied screenshots; replace with original high-resolution assets when available.
League Spartan and Lexend Deca load from Google Fonts. Loubag is not bundled; add your licensed font file in public/fonts and enable the @font-face rule in src/styles.css. Georgia is the temporary title fallback.
Project buttons, See All, LinkedIn and Jobstreet are intentionally disabled until destinations are supplied. Navigation and the email link work.
